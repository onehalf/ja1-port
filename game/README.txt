Put your Jagged Alliance game files here.

Copy the whole GOG "Jagged Alliance" folder (the one with JA1.gog and JA.EXE) into this folder, then start
ja1-port. A subfolder is fine: game/Jagged Alliance/JA1.gog works.

Windows: if you installed the game with the GOG installer or GOG Galaxy in the default place, you do not need to
copy anything: ja1-port finds C:\GOG Games\Jagged Alliance and the GOG Galaxy games folder by itself.

Linux: GOG sells the game as a Windows installer. Put setup_jagged_alliance_*.exe into this folder and run
./install-from-gog.sh beside ja1-port (it needs innoextract: sudo apt install innoextract).
